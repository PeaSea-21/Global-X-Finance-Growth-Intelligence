# 台灣官方資料 Demo 使用說明

這是一個本機展示工具。它會保存臺灣證券交易所（TWSE）官方 OpenAPI 的原始資料，再把官方欄位整理成可回查 Evidence 的標準化記錄與規則研究卡。它不會產生選股、買賣建議或自動發文。

## 第一次怎麼打開

1. 確認電腦已安裝 Python 3.11 或更新版本。
2. 回到專案最外層資料夾，雙擊 `启动台湾Demo.bat`。
3. 第一次啟動會建立獨立環境並安裝必要元件，通常會比之後啟動久。
4. 等待命令視窗顯示「啟動完成」，瀏覽器會自動打開首頁。

如果瀏覽器沒有自動打開，可手動進入 `http://127.0.0.1:8765/`。

## 平時怎麼同步

打開首頁後，點擊藍色的「同步台灣官方資料」。系統只會連線到來源註冊表中標為 `API_VERIFIED` 的 `TW-A02`，不會自動採集其餘待審查或受限制來源。

完成後會顯示：本次官方 API 回傳的「抓取」筆數、第一次保存的「新增」筆數、資料庫已經存在的「重複」筆數，以及新標準化記錄和新規則卡數量。每個資料集都有獨立的採集記錄和完成時間。

首頁的「資料新鮮度」依官方資料日期顯示。如果最新資料不是電腦當天日期，頁面會明確標為「官方最新可用資料」，不會把休市日或較舊日頻資料寫成即時行情。

## 怎麼查看官方信號卡

點上方「官方信號卡」，可以看到成交量較高、成交金額較高、當日漲跌較明顯，以及外資及陸資持股比例研究卡。

每張卡都是 `RULE_BASED_OFFICIAL_SIGNAL`，會列出資料日期、計算依據、公式版本、抓取時間、資料新鮮度、風險提示、原始 Evidence 和官方 URL。這些卡只做日頻官方資料的透明規則排序，不代表即時熱點或投資建議。

可使用「資料日期」下拉選單篩選，或輸入股票／證券代碼搜尋。資料較多時，頁面底部可切換上一頁、下一頁。

## 怎麼查看 Evidence

點上方「Evidence」，選擇一筆記錄，再點「查看 Evidence 詳情」。詳情頁可以看到完整原始 JSON、官方 URL、來源、發布時間、抓取時間、SHA-256 內容哈希、資料標籤和採集批次。

`REAL_OFFICIAL_SOURCE` 表示這筆資料是在正常執行時從官方端點取得；測試程式建立的內容只會標為 `SYNTHETIC_TEST_DATA`。

## 「新增」和「重複」是什麼

- 新增：這筆官方記錄第一次出現，系統已保存完整 Evidence。
- 重複：同一來源 URL 或同一內容哈希已經存在，系統只計數，不再寫一份，也不會覆蓋第一次保存的內容。

所以第二次同步相同資料時，新增通常下降、重複增加，這是去重正常運作，不是漏資料。

## 頁面出現紅色錯誤怎麼辦

先進入「採集記錄」，查看紅色的錯誤代碼、原始錯誤訊息和失敗時間。確認網路正常後可稍後再按一次同步。官方服務暫時無法使用時，系統會如實顯示失敗，不會用假資料補成成功。

若錯誤持續，請截下「採集記錄」頁交給技術人員；不要自行修改來源網址。

## 如何安全關閉

回到啟動 Demo 的黑色／藍色命令視窗，按 `Ctrl+C`，確認後即可關閉視窗。資料已保存在本機，不會因關閉頁面而消失。

## 目前還沒有的功能

- 美國官方來源尚未提供，只保留空白 Market Pack 模板。
- 不採集尚未 `API_VERIFIED` 的媒體、論壇、KOL 或受 robots／授權限制來源。
- 不做 AI 財經觀點、內容文案、投資建議或自動發佈。
- 不宣稱已完成兩小時即時熱點；目前使用的是官方日頻資料。
- 不做登入繞過、付費牆繞過、代理 IP、帳號池或自動互動。
