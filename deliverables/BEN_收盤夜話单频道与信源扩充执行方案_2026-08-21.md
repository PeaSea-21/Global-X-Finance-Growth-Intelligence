# BEN「收盤夜話」单频道与信源扩充执行方案

## 先说结论

可以先换成「收盤夜話」。这个频道比「产业透视镜」更适合现在开工，因为它每天都能产出，也最直接检验系统有没有真正替 Ben 省时间。

但现在不能直接说“已经能稳定自动生成 15 分钟成稿”。现有页面的「收盤夜話」只是从另外三个频道各拿一条候选拼出来的预览，缺少频道简介明确要求的三大法人、融资融券、期货和期权。先把这些盘后数据补齐，再让新闻、X 和 YouTube 讨论进入选题，生成的稿才不是一张涨跌榜换个说法。

这轮已经把用户给的资料整理成 `PROVISIONAL` 初版 Style Pack。它能指导第一批标题和文稿，但只有一篇完整口播、另一篇只有简介，不能假装已经完全学会这个频道。

## 这个频道真正要交付什么

每天不是只生成一篇，而是先给 Ben 五个不同的「今晚可以怎么讲」：

1. 每个选题先给 2–3 个标题。
2. 每个选题写清楚为什么是今天、为什么适合「收盤夜話」。
3. 每个选题都要有大盘结构、主角股票、利多与限制、明日观察点。
4. 排名前三的选题生成完整繁体中文口播稿，目标 1,600–2,800 字；剩下两条保留为备选提纲。
5. 每个数字和关键说法旁边直接显示来源卡，Ben 点一下就能打开原文核实。

五个选题必须是五种不同的盘面解释，不能把同一只涨幅榜股票换五个标题：

- 大盘冲高回落或低开高走，真正的转折是什么。
- 指数变化不大，但市场广度或类股轮动很剧烈。
- 外资现货、期货部位和内资方向出现分歧。
- 一至两个主角股票代表了当天最强的事件或情绪冲突。
- 今天的走势给明天留下了什么可以验证的条件。

## 从两篇「收盤夜話」里学到了什么

目前能确认的写法：

- 标题喜欢把两个主角、盘中反转和大盘悬念放在一起。
- 开头先说今天最刺激或最反常的地方，再问这是主线、洗盘还是出货。
- 中段分别还原两只股票怎么涨、怎么跌，再把它们放回同一个产业或市场背景。
- 结尾不直接给一个确定答案，而是留下“如果发生 A，就看什么；否则要防什么”的观察题。
- 语气像朋友聊盘，可以有比喻和反问，但数据才是正文骨架。

目前还不能确认：

- 这个频道面对全面上涨、全面下跌、指数横盘等不同盘型时是否都用同一套结构。
- 固定转场、口头禅和平均句长，因为第二篇没有完整口播。
- 频道简介承诺的三大法人、融资券和类股排名在真实节目里怎么讲，因为现有完整样本没有充分展示。

所以第一版会保留“好懂、有冲突、两只主角”的优点，同时补上完整盘面，不照抄原稿里的句子或口头禅。

## 每篇文稿的固定骨架

1. **开场冲突**：一句话讲今天最反常的盘面，提出整集问题。
2. **大盘快照**：加权指数、成交值、涨跌家数，说明是普涨、普跌还是结构行情。
3. **类股强弱**：最强和最弱类股各是谁，强势有没有扩散。
4. **主角一**：盘中路径、官方事件、成交和机构动向。
5. **主角二/反方力量**：为什么同族群另一只不同步，或是谁拖累了大盘。
6. **钱往哪走**：外资、投信、自营商，融资融券和借券变化。
7. **期权/期货验证**：台指期、基差、未平仓、三大法人期货部位和 Put/Call Ratio；没有数据就明确写未接入。
8. **多空拉扯**：把支持继续走强的事实和可能降温的条件并列。
9. **明日三件事**：三个能用下一交易日数据验证的观察点。
10. **结尾互动**：问观众如何理解这个分歧，并保留“不构成投资建议”的边界。

不会保留样本里的加 Line、老师带单、免费飙股、精确进出场或收益保证。

## 先补哪些数据

### 第一优先：当天盘面骨架

| 要回答的问题 | 需要的数据 | 当前情况 |
|---|---|---|
| 今天大盘到底强不强 | 加权指数收盘、涨跌、成交值 | 已有部分官方数据，但页面没有完整组织成频道稿 |
| 是普涨还是少数股票撑盘 | 上涨/下跌/平盘家数、上市与上柜市场广度 | `NEEDS_IMPLEMENTATION` |
| 哪些类股真强、哪些只是单股 | 官方类股指数、类股内涨跌家数和成交占比 | 现有行业映射只能做候选，需要补盘面广度 |
| 谁在买、谁在卖 | 外资、投信、自营商总额和个股买卖超 | `NEEDS_IMPLEMENTATION` |
| 杠杆情绪有没有变 | 融资融券、借券卖出与变化 | `NEEDS_IMPLEMENTATION` |

### 第二优先：期货和期权

接 TAIFEX 的公开盘后资料，至少包括：

- 台指期收盘、期现货基差、成交量和未平仓量。
- 外资、投信、自营商期货多空净部位。
- Put/Call Ratio。
- 主要选择权履约价的成交与未平仓分布；只讲已经定义清楚的指标，不凭一张数字表猜“主力意图”。

这部分正好补上 Ben 对「權值旗艦」的反馈，也能让「收盤夜話」不只是讲股价。

### 第三优先：新闻和讨论

- MOPS、公司 IR、TWSE/TPEx/主管机关新闻稿负责事实。
- Yahoo奇摩、CNA、Google News RSS 等负责发现原始报道，页面显示原媒体、标题、时间和链接。
- 现有 67 个 X 账号负责判断谁在讨论什么，仍然标为 `OPINION`。
- YouTube 先抓频道新标题、发布时间和链接，用来证明“这个主题开始有人讲”，不拿博主说法替代官方事实。
- 同一媒体集团重复转载只算一个独立来源，转发不增加独立讨论数。

2026-08-20 的实际页面包里已经有 79 条新闻、649 条 X 和 25 个媒体事件。眼下第一问题不是数量为零，而是这些内容没有进入最终「收盤夜話」候选。实现时先修路由：新闻、公告、X、价量、法人和期权资料要围绕同一个事件合并，然后再排选题。

## 热点怎么判断

先过硬门槛，再排名，不先拍一个 0–100 的神秘分数。

一个题能进入五强，至少要满足：

- 数据属于同一个已完成交易日，较早资料必须标时间。
- 有一个市场级问题，而不是“某股今天涨很多”。
- 至少两个不同类别的来源，其中一个是官方或公司原始来源。
- 同时有一项盘面结构证据，以及一项事件、讨论或资金证据。
- 主角股票有市场代码、当天数据和可点击来源。
- 能写出明天怎么验证，而不只是复述今天发生了什么。

合格后按下面顺序比较：事件重要性、影响范围、独立讨论是否升温、新颖程度、证据强度、频道契合度、明日验证是否清楚。Ben 连续使用一段时间并留下保留/淘汰原因后，再决定是否需要固定权重。

页面要把候选分成：`确认热点`、`刚发生但讨论还没扩散`、`盘面先动但催化剂待查`、`备选`、`普通噪音`。价量异动只能进入第三类，不能自动变成热点。

## 页面怎么呈现

进入「收盤夜話」后先看到五张大标题卡。点开一张：

- 左边/上面是标题选项和完整口播稿。
- 右边/下面是“为什么今天”“事实”“解释”“还不知道”“明天看什么”。
- 股票表只放文稿真正提到的公司，显示代码、收盘、涨跌、成交量和必要的法人数据。
- 来源卡直接显示 `TWSE｜加权指数收盘｜13:55`、`TAIFEX｜台指期三大法人｜14:12`、`Yahoo奇摩｜文章标题｜12:48`，点击打开原文。
- 原始 JSON 放到最后的“查看原始资料”，不让 Ben 先读机器字段。

每张选题卡增加三个反馈按钮：`可直接用`、`改后可用`、`不用`，再选一个原因。这个反馈比播放量更早，能直接训练系统知道 Ben 为什么不要某个题。
