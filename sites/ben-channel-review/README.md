# BEN Channel Review

Public, read-only review page for the three P06B Taiwan channel pilots.

- `brief.json` is a reviewed daily or historical P06B artifact; the page labels the mode from `replay_mode`.
- The page deliberately downgrades technical `READY` and `READY_TO_PITCH` wording to business-readable review states.
- Browser feedback is local-only and does not create a server write path.
- This is not intraday realtime data, investment advice, or evidence of completed production source rights.
