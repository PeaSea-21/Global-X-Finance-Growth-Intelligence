## 七个有文稿频道

### 2. 收盤夜話

- 频道感：下班后朋友聊盘，先把今天最反常的地方说出来，再用指数、广度、类股和主角股票拆开。
- 最稳结构：盘面情绪 → 指数/成交 → 类股强弱 → 两个主角 → 法人与未知项 → 明日三个检查点。
- 标题：盘面冲突 + 双主角/族群 + 关键数字 + 明日悬念。
- 必须改进：样本没有兑现完整的三大法人、融资券和大盘广度承诺；生产稿必须补齐或明确 `UNKNOWN`。
- 不学习：Line 导流、老师荐股、飆股名单和模板化互动。

### 4. 權值旗艦

- 频道感：战局式、快节奏，用两只权值股的“对打”解释指数。
- 最稳结构：大盘振幅 → 权值 A → 权值 B → 指数贡献/期现货 → 技术关卡 → 未来两日情境。
- 标题：指数关卡 + 权值 A PK 权值 B + 筹码风险 + 下一站。
- 最大风险：样本频繁把“外资故意压盘、洗盘、吃货”写成事实。后续只能写成解释假设，并给 TAIFEX、权重和法人来源。

### 5. 資金雷達

- 唯一样本是欣兴单股，表现为“极端价量 → 产业周期 → 法人 → 技术过热”。
- 但频道画像承诺的是产业指数、成交份额和法人跨板块迁移。两者不一致。
- 当前只能暂存单股样本特征，不能据此定义“资金雷达”的正式口吻。下一批最需要的是至少两篇真正比较 3 个以上产业/板块的稿。

### 6. 那指火箭

- 频道感：把颠覆性制度或科技事件讲成一条时间线，强调亚洲投资者会受到什么影响。
- 最稳结构：事件结论 → 规则/时间线 → 为什么现在 → 亚太影响 → NDX/QQQ联动 → 清算和流动性风险。
- 必须核对 SEC/交易所原文、实施条件、夏令时换算；“计划上线”不能写成“确定上线”。

### 7. 板塊輪動儀

- 两篇稿都不是板块轮动，而是 NVDA 与 AAPL 单股深拆。
- 可保留的只是“矛盾钩子 → 技术 → 财报 → 产业 → 机构分歧 → 情境”的深拆顺序。
- 正式频道必须有至少 3 个板块或 XLK/XLF/XLE/XLV 等 ETF 的相对强弱与驱动比较。没有跨板块证据，就不能使用这个频道名义输出。

### 8. 暗池雷達

- 频道感：现货看起来平静/大涨，但期权市场出现反向大单，用悬疑方式拆合约。
- 最稳结构：现货钩子 → 到期日/行权价/CallPut → 成交/OI/IV/Delta → 催化 → 多种意图 → 验证点。
- 最大风险：大额 Put 可能是保护、组合腿、平仓或方向下注；成交不等于开仓，期权流也不等于暗池。没有原始成交方向与暗池打印，不能说“机构已押注崩盘”。

### 9. 期權守門人

- 频道感：教学型、克制、风险优先，用历史规律或大师案例解释不对称损益。
- 最稳结构：误区 → 历史案例 → 三层机制 → 最大损失/收益结构 → 普通人分层行动 → 限制条件。
- 当前更像风险教育频道，还不足以证明会稳定做 IV Rank、Covered Call、Cash-Secured Put 等日常策略。
- 历史收益、回撤和季节性规律必须能点到原始研究或数据，不能只引用故事。

## 三个无文稿频道

`個股顯微鏡`、`產業透視鏡`、`財報獵人` 目前都标记为 `NO_TRANSCRIPT_NEEDS_SAMPLES`。频道简介可以决定“该抓什么证据”，不能决定“该怎么说话”。在收到至少 2 篇完整稿前，不生成确定的标题公式、开场口吻或结尾话术。

## 共用生产规则

1. 新鲜事件以最近 24 小时为主，48 小时只作背景；价量异动只是线索，不自动成为热点。
2. 每篇开头显示 `正文字符数`，统计实际完整文稿，不统计标题、来源卡和免责声明。
3. Ben 点开的首要来源必须是人类可读的官网文章、公告或对应查询页；API/JSON 只能作为第二层审计证据。
4. 周一至周五和周日都采集；周六不运行。周日没有台股同日收盘，任务只做 24/48 小时新闻与注意度快照，不伪装成盘后稿。
5. 所有样本只用于原创的频道结构和节奏研究；事实必须从当日独立 FactPack 获取。
