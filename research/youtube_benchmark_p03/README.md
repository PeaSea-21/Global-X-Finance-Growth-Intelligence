# P03：YouTube 财经博主对标与叙事模板研究

> 状态：**研究与设计完成；未实施、未安装、未接入、未运行第三方仓库功能**
> 核验日期：2026-08-16（Asia/Shanghai）
> 范围：台湾及华语股票财经 YouTube 内容工作流

## 结论

五个仓库都只能提供局部能力，没有任何一个可以原样满足“频道发现 → 爆款筛选 → 字幕 → 结构分析 → 风格画像 → 多博主融合 → 以新事实生成原创 YouTube/X 内容”的完整要求。

推荐采用 **1 个主 Skill + 1 个可选数据适配器**：

1. `finance-youtube-benchmark`：唯一业务 Skill，负责研究编排、结构/节奏/风格分析、合成风格包、事实闸门、原创脚本、X 改写与验收。
2. `youtube-acquisition-adapter`：不是第二套内容方法论，只负责频道/视频元数据与字幕获取；生产接入前必须单独完成平台条款、商业使用、凭据与数据保留审查。

不建议安装五个完整仓库的合集。应只借鉴以下模式并重新实现为仓库专用规范：

| 来源 | 借鉴 | 不直接采用 |
|---|---|---|
| `youtube-skills` | 单一 API 取得频道、视频和字幕的接口思路 | 自动注册、持久写入 API Key、第三方缓存与把 12 个别名 Skill 全部安装 |
| `nova-youtube-agent` | 竞品异常视频、证据标签、已发布/拒绝/表现反馈闭环 | Hermes 专用目录、独立 memory 系统、宽泛工具依赖 |
| `storytelling-skills` | 频道公式、赢家/失败对照、开环链、重钩子、标题封面承诺一致 | 九个重复触发的通用 Skill 全套安装 |
| `claude-youtube` | 官方 API 低配额 uploads-playlist 路径、私有分析与公开竞品指标分离 | Claude 专用编排、过宽命令集、`yt-dlp` 字幕路径、简单均值爆款算法、未校准基准 |
| `text-trainer` | 多维度语言/结构分析和反模式 | 仿写某个自然人、保存代表性原文样本、把署名创作者的口头禅作为生成目标 |

## 核心治理结论

- **事实与风格必须物理分离**：`FactPack` 只能由可靠来源构成；博主视频一律默认 `OPINION`，不能自动升级为财经事实。
- **字幕只作临时分析材料**：默认不把完整字幕写入永久成果；永久保存时间戳索引、哈希、结构标签和高层特征，不保存长篇逐字稿。
- **不得模仿单一具名创作者**：研究报告可注明来源频道，生成阶段只使用去身份化的复合风格维度，不使用标志性短语、口头禅或可识别句式。
- **爆款不是事实质量**：播放量只表示注意力。任何异常视频筛选都必须保存采样时间、视频年龄、比较基线和数据来源。
- **平台条款是上线闸门**：YouTube 官方开发者政策对抓取、数据存储和衍生指标有严格限制。自动计算竞品“爆款分”在合规批准前应标为 `BLOCKED_FOR_TERMS_REVIEW`，不得假设可商用。
