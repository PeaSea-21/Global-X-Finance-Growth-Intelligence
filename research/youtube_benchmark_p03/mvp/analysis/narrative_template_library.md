# 可复用叙事模板库

## T01：决策问题—证据拆分—风险边界

1. 用一个具体决策问题开场，但不提供买卖指令。
2. 先列 2–3 个官方事实，再解释哪些支持、哪些不支持该判断。
3. 把同一题材拆成“增长引擎 / 约束 / 待验证指标”。
4. 结尾明确事实时点、情境与风险。

适用：台股盘面、财报快评、ETF机制。禁止：全压、稳赚、目标价保证。

## T02：三问预告—逐章深拆—判断更新

1. 开场承诺本集回答三个互相关联的问题。
2. 每章固定为 `事实 → 解释 → 反方 → 小结`。
3. 第三章回到共同主问题，说明旧判断是否需要更新。
4. 单一 CTA，不夹带个人故事或来源频道包装。

适用：科技公司财报、AI产业链、产品与组织变化。

## T03：宏观事件—传导机制—产业落点

1. 从可核验宏观或公司总量数据出发。
2. 解释资金/需求如何传导到平台、制程或供应链。
3. 对照受益与成本压力，列下一项验证指标。
4. 把预测改写成条件情境，不下确定结论。

适用：美股与台股联动、利率到科技估值、半导体周期。

## Composite v0.1

- `hook`: T01 的单一决策问题，权重 0.33。
- `chaptering`: T02 的三问逐章回收，权重 0.33。
- `evidence_order`: T03 的数据→机制→产业→风险，权重 0.34。
- `forbidden`: 具名模仿、固定口头禅、个人经历、来源特有比喻、无来源荐股。
