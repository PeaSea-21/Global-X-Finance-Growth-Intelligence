# 收盤夜話單頻道試點

本目录保存「收盤夜話」的初版频道写作合同，不保存用户提供的完整文字稿。

- `style_pack_v0.1.json`：频道定位、样本证据、标题/叙事规律、每日输出字段、选题门槛和禁用边界。
- 当前状态：`PROVISIONAL_TWO_FULL_TRANSCRIPTS`。
- 两篇完整口播可以支持反复出现的结构判断，但两篇都集中在记忆体双雄，仍不能代表频道在不同盘型下的稳定声音。
- 重复出现的 Line、老师、飙股名单和进出场导流只作为排除证据，不进入生成风格。
- 三份大附件按 SHA-256 记录为旧号结构参考，不能作为当天财经事实，也不能直接移植某个账号的口头禅。

升级条件是至少 5 篇、最好 10 篇「收盤夜話」完整发布稿，覆盖不同盘型，并补上 Ben 的保留/淘汰理由。
