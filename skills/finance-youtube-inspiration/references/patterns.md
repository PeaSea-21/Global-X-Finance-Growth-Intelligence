# Creator-neutral pattern palette

These are benchmark-derived hypotheses, not proven growth laws.

## P1 — Single decision question

Use for one stock, earnings release, ETF, or explicit investor decision. Sequence: object → question → decisive evidence → positive case → risk → watch condition.

## P2 — Three-item update ledger

Use when three independently evidenced events share one market theme. Sequence: event/impact ×3 → common thesis → next observation. Avoid three unrelated headlines.

## P3 — Macro-to-micro chain

Use for Fed, inflation, jobs, rates, currency, or geopolitics. Sequence: event → data → financial variable → industry → company → stock → invalidation condition.

## P4 — Consensus challenge

Use only with real conflicting evidence. Sequence: common interpretation → overlooked data → alternative explanation → second-order effect → counterargument → conditional conclusion.

## P5 — Data-led deep dive

Use for earnings and official statistics. Sequence: primary number → comparison → drivers → business/market impact → scenario → next data point.

## P6 — Evidence-first event explainer

Use for breaking news. Sequence: confirmed event → confirmed facts → why it matters → affected parties → unknowns → next verification.

## P7 — Risk and opportunity pair

Pair one verified catalyst with one verified limitation. Do not manufacture conflict or imply guaranteed returns.

## Packaging principles

- Questions define an audience task; they are not a proven CTR button.
- One visible hierarchy is more defensible than a universal color or face formula.
- Let title and thumbnail complete each other rather than repeat the same sentence.
- One official number can be a proof point; it cannot substitute for a thesis.
- Expert identity and screenshots create evidence appearance, not factual proof.
