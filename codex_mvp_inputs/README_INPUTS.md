# 使用方法

1. 将本文件夹中的全部文件复制到 Codex 当前项目根目录。
2. 不需要新建聊天界面；回到刚才输出 `BLOCKED_MISSING_VERIFIED_SOURCE_REGISTRY` 的同一 Codex 会话。
3. 把 `CODEX_FOLLOWUP_PROMPT.md` 的全部内容发送给 Codex。
4. 确认 Codex 的 Input Audit 显示注册表已找到，共 17 行来源。
5. 若它仍说文件不存在，说明你只在聊天中发送了文字、没有把文件放进它正在操作的项目目录。此时先上传/复制文件，再继续。

本启动包只解决第一阶段输入缺失，不代表已经取得所有网站的自动抓取许可。
